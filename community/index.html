EVALUATION PROTOCOL

What the scores mean.

Original benchmark metrics. Explicit cohorts. Comparable denominators.

1. What is one leaderboard entry?

Each row is a submission series: a named method, team or curated design collection. This preview contains two curated collections, Research archive and Published references. A collection retains one selected eligible design per surface. Our archive includes different search campaigns and researcher-guided work; its aggregate is not a same-budget agent result.

Reference cohorts identify current and historical reference sets. They do not imply two independent ten-task agent runs. A historical design can be used in a cohort only when its physical settings and evaluation protocol are compatible.

2. Composite score and eligibility

The per-design composite comes from the unmodified StellCoilBench evaluator. Higher is better. All hard checks and all nine soft metrics must be present before a design can be ranked. A hard failure is shown as ineligible; a missing or incompatible result is shown as unavailable.

Field error Bn is displayed separately and lower is better. The soft-target count tells you how many of the nine targets are met. A high composite score does not necessarily satisfy all nine targets.

3. The overall mean

Mean composite = (score₁ + score₂ + … + scoreₙ) / n

The mean is an equal-weight arithmetic mean of the per-surface composite scores, with no extra weighting or normalization. This cross-surface aggregation is a proposed preview convention, not an official upstream overall metric.

Matched surfaces: both collections use the exact same fixed set of completely verified, compatible pairs. Current references use eight surfaces; historical references use nine. The denominator never changes independently for each row. If a required result is missing or becomes incompatible, the subset mean and its rank are withheld.

All 10 surfaces: an overall rank requires all ten compatible results for every compared entry. This snapshot does not meet that requirement. The full-suite mean is unavailable; missing scores are not filled with zero, and incomplete rows do not receive a full-suite rank.

4. Evidence and unresolved cases

Paired scores require identical protocol hashes, evaluation grids and physical settings. The primary comparison uses 128 × 128 evaluation; recent warm-start results also received independent fresh128 confirmation. Stored public scores are distinct from re-evaluated scores.

Current Schuett has a 64-grid vacuum result and no matched 128-grid reference using the same physics. The rotating-ellipse references fail a hard constraint in both cohorts. Their records remain visible, but neither case produces a fabricated ranking or a win over zero.

Each design’s detail panel links to a sanitized metric report and file hashes. This is a curated local research snapshot, not a complete re-evaluation of all public submissions or an officially accepted ranking.
